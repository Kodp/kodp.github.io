这是一篇示例文章，用来演示博客文章 frontmatter、Markdown 内容和自动发布流程。

  • Astro

欢迎来到你的新博客。

这个项目已经预先配置好了：

  • Astro 静态站点
  • Markdown / MDX 内容集合
  • GitHub Actions 自动构建
  • GitHub Pages 自动发布

以后你只需要在 src/content/blog/ 里新增一篇 Markdown 文件，就可以写文章。

建议写作流程

  1. 复制一篇现有文章作为模板。
  2. 修改 frontmatter。
  3. 填写正文内容。
  4. 本地预览没有问题后，提交并推送到 GitHub。
